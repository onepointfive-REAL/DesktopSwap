# Desktop Swap
Desktop Swap is a easy wrapper (desktop shortcut toggle) for "Primary taskbar on secondary monitor" (taskbar-primary-on-secondary-monitor) by m417z

Intructions:
1. Download Source Code ZIP
2. Download "windhawk_setup_offline_alpha_6.exe" from releases
3. Extract the ZIP
4. Put "windhawk_setup_offline_alpha_6.exe" in the same directory
5. Run the "RUN ME - installer.bat"
6. Allow admin
